# Formalization of Integral Matrices of Fixed Rank

This repository formalizes the results of [*Integral matrices of fixed rank
over number fields*](https://arxiv.org/abs/2510.11673).

The formalized main results are:

- the asymptotic count of bounded integral matrices of fixed rank over a
  number field;
- convergence of moments of lifts of codes to the paper's echelon-integral
  limit.

The formalization uses Schmidt's height-counting theorem as an explicit input
and formalizes the relevant Fieker--Stehlé result on successive minima over
number fields.
